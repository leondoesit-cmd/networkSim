# NetMap Pro — מדריך והכשרת תקשורת ורשתות רמה ב' (עיריית רעננה)

פלטפורמת למידה טופוגרפית אינטראקטיבית וסימולטור שטח ייעודי מ-0 לתפקיד **איש/ת תקשורת ורשתות רמה ב' (משרה 7274)** באגף מערכות מידע ותקשורת, עיריית רעננה.

---

## 🌟 מה כוללת המערכת?

### 1. המקרה החי: "מפל אחוזה — ראשון 07:14" (Case Theater)
סימולציית שטח מקיפה שבה כל 17 נושאי המסלול נפרסים בתוך אירוע עירוני בודד:
- **8 אתרים עירוניים:** חדר שרתים ליבה (אחוזה 103), מוקד 106, ארון צומת ויצמן (LPR), אגף הנדסה (קומה 2), פארק רעננה, תיכון אוסטרובסקי, קאנטרי ושער ה-ISP הכפול (FortiGate HA).
- **5 תקלות מוקד מצטלבות:** נפילת מצלמות LPR עקב מגבלת תקציב PoE, שמע רובוטי במוקד 106 עקב היעדר QoS/FIFO על רקע גיבוי שרתים, שיתוק אגף הנדסה עקב סופת Broadcast (לולאת STP מסוויץ' ביתי ללא BPDU Guard), עמדות תקועות ב-APIPA עקב היעדר DHCP Helper ב-SVI 40, והאטת אינטרנט עקב חנק PAT.
- **7 שלבי תחקיר כרונולוגיים ומפת רשת אינטראקטיבית:** חלוקה לפי שכבות מודל ה-OSI (L1–L7) ופקודות CLI מוכחות.

### 2. 10 מעבדות שטח וארגזי כלים (Labs)
1. **עץ מיומנויות (Skill Tree):** היררכיה מלאה ומסלול התקדמות טכנולוגי.
2. **מפה טופוגרפית (0–1000m):** מפת גבהים לפי רמות מורכבות (תשתיות פסיביות, מיתוג, שו״ב, עיר חכמה, ניהול שטח וספקים).
3. **מפת ה-NOC וארונות שרתים (Topology Explorer):** תרשים טופולוגי חי של מתגי ליבה, ארונות שטח ושרתים.
4. **מסלול חבילת מידע (Packet Journey):** ויזואליזציה צעד-אחר-צעד של מעבר חבילה ברשת העירונית.
5. **מעבדת CLI אינטראקטיבית (Sandbox):** סימולטור פקודות Cisco IOS / Aruba / Linux בשטח.
6. **מחשבון סאבנטינג ו-VLSM:** כלי חישוב טווחים, מסכות רשת וכתובות שידור (Broadcast).
7. **מעבדת סיבים וכבילה (L1):** סוגי מחברים (LC/SC/ST), כבלים (SM/MM, Cat6A) ותקציב ניחות dBm.
8. **סימולטור תקלות שטח (Triage Simulator):** תרחישי תקלות בזמן אמת לתרגול אבחון מהיר וקבלת החלטות.
9. **סימולטור ראיונות עבודה (Interview Prep):** מאגר שאלות מקצועיות ממוקדות למכרז 7274.
10. **דף נוסחאות ותרשימי עזר (Quick Reference):** טבלאות קיצורים, פורטים, מסכות ופקודות שכיחות.

### 3. יועץ AI חכם של עיריית רעננה (Gemini AI Advisor)
מנטור תקשורת חכם המופעל על ידי Google Gemini API ומותאם ספציפית לדרישות משרה 7274, עם דוגמאות מוחשיות מאתרי העיר רעננה.

## 🚀 הרצה מקומית (Run Locally)

**דרישות מוקדמות:** Node.js (גרסה 18 ומעלה)

1. התקנת תלויות:
   ```bash
   npm install
   ```
2. הגדרת מפתח ה-API של Gemini בקובץ `.env`:
   ```bash
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
3. הרצת שרת הפיתוח:
   ```bash
   npm run dev
   ```
4. פתח את הדפדפן בכתובת `http://localhost:3000`.

לבניית פרודקשן:
```bash
npm run build
npm run start
```
